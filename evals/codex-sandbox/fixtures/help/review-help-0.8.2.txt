Usage: coderabbit review [options] [command]

AI-driven code review for the current Git workspace

Options:
  -V, --version            output the version number
  --deep [focus]           Use the full pull request review policy (focus text
                           requires early access)
  --fresh                  Review selected changes without reusing the previous
                           local checkpoint
  --show-prompts           Print AI prompts without starting a new review
  --agent                  Emit structured findings for agent workflows
  --use-credits            Use usage credits if this review exceeds included
                           limits
  --committed              Review only committed changes
  --uncommitted            Review uncommitted Git changes
  --include-untracked      Also review files that have not been added to Git
  -c, --config <files...>  Additional instructions for CodeRabbit AI (e.g.,
                           claude.md, coderabbit.yaml)
  --base <branch>          Git base branch for comparison
  --base-commit <commit>   Git base commit on current branch for comparison
  --dir <path>             Review only changes inside this directory
  --remote <owner/repo>    Review a GitHub repository on the server without a
                           local checkout
  --source-branch <ref>    Source branch or ref to review with --remote
  --api-key <key>          API key for authentication
  --usage                  Show included reviews and billing-period usage
                           instead of reviewing (alias of `coderabbit usage`)
  --region <region>        Region for inline API key authentication (choices:
                           "us", "eu")
  -h, --help               display help for command

Commands:
  findings [options]       Show findings from the previous local review

Examples:
  coderabbit review                           # Review tracked changes
  coderabbit review --committed               # Review only committed changes
  coderabbit review --uncommitted             # Review uncommitted Git changes
  coderabbit review --include-untracked       # Also review files not added to Git
  coderabbit review --agent                   # Emit structured findings for agents
  coderabbit review --deep                    # Use the full pull request review policy
  coderabbit review --fresh                   # Review selected changes without the previous local checkpoint
  coderabbit review --show-prompts             # Print prompts from the latest local review
  coderabbit review --base main               # Compare current branch against main
  coderabbit review --dir /path/to/workspace  # Review changes inside that directory
  coderabbit review --region eu --api-key <key> # Review with an EU API key without storing it
  coderabbit review findings                  # Show previous local review findings
  coderabbit review findings --clear          # Forget stored findings for this scope
  coderabbit review --remote coderabbitai/mono --base main --source-branch my-feature
                                              # Review a GitHub repository without a local clone

Notes:
  Plain text is the default review mode.
  Use coderabbit auth login --agent for agent-driven OAuth login.
  --remote requires --base and --source-branch, and runs outside any git checkout.
